# AI-BugHunter Demo Artifact Index

This directory contains the immutable, sanitized outputs generated by the automated local demonstration workflow.

## Artifacts

### `demo-summary.md`
- **Purpose**: A high-level recap of the executed demo, confirming the environment, the 9-step workflow, and the demonstrated security boundaries.

### `ai-bughunter-demo-report.md`
- **Purpose**: The final, human-readable vulnerability report containing only findings that were explicitly validated by the researcher.

### `ai-bughunter-demo-report.json`
- **Purpose**: The raw JSON payload of the final report, suitable for downstream ingestion.

### `demo.log` (located in `../logs/demo.log`)
- **Purpose**: The time-stamped execution ledger. Proves that the exact required safety checks and human-interaction stages occurred sequentially.

### Execution Evidence (`03_execution.json`)
- **Purpose**: The raw output from the `SafeExecutor` hitting the local lab, paired with the AI's hypothesis. 
- **Security Check**: This file must demonstrate successful redaction of sensitive headers (e.g., `Bearer [REDACTED]`).

### Validation Result (`05_validation.json`)
- **Purpose**: Contains the explicit state transition of the finding from `NEEDS_VALIDATION` to `RESEARCHER_CONFIRMED`.
